# Transcription & Content Toolkit

A practical toolkit for turning audio and video into clear, usable written content: transcripts, subtitles, captions, and voiceover-ready scripts.

> **Status:** Portfolio foundation with templates, fictional examples, and quality checklists. Examples are demonstrations, not transcripts of real recordings.

## What's included

- **Transcript style guide** — speaker labels, timestamps, uncertainty, and readable formatting.
- **Voiceover script template** — narration, pacing, pronunciation, and production notes.
- **Sample transcript** — fictional sample showing speaker labels and timestamps.
- **SRT and WebVTT samples** — starter subtitle files with valid basic structure.
- **Quality-control checklist** — accuracy, synchronization, readability, and final delivery checks.

## Typical workflow

1. Confirm the brief, language, audience, deliverables, and deadline.
2. Review the source recording and note audio-quality issues.
3. Draft the transcript; mark unclear speech instead of guessing.
4. Verify names, numbers, terminology, and timestamps against the recording.
5. Create and synchronize captions or subtitles when requested.
6. Adapt approved content into a voiceover script if needed.
7. Run the checklist and deliver files using clear filenames.

## Quality principles

- **Accuracy over polish:** never silently invent words.
- **Transparent uncertainty:** flag unintelligible or ambiguous speech.
- **Consistent formatting:** use a stable speaker-label and timestamp style.
- **Accessible captions:** prioritize readable line breaks and synchronization.
- **Privacy:** handle recordings and personal information only as authorized.
- **Honest scope:** distinguish verbatim transcription from edited or summarized text.

## Folder guide

- `templates/` — reusable starting points.
- `examples/` — fictional samples to demonstrate formatting.
- `checklists/` — repeatable quality checks.

## File formats

- Plain transcript: `.txt` or `.md`
- SubRip subtitles: `.srt`
- WebVTT subtitles: `.vtt`
- Voiceover script: `.md` or `.docx` as requested

## Limitations

The sample files are illustrative and have not been generated from an audio recording. Real work should be checked against the source media. Caption timing and line lengths should be adjusted to the client's platform requirements.
