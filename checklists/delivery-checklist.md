# Transcription Project Delivery Checklist

## Before work
- [ ] Confirm source access and permission to process the recording.
- [ ] Confirm language, output style, speaker labels, timestamp needs, and deadline.
- [ ] Confirm deliverables, file formats, revision scope, and naming convention.
- [ ] Review any glossary, reference spellings, or client style guide.

## Transcript review
- [ ] Listen through the full source; do not rely only on automated output.
- [ ] Verify names, numbers, dates, acronyms, and technical terms.
- [ ] Mark unclear speech transparently; never guess silently.
- [ ] Check speaker attribution and overlapping speech.
- [ ] Confirm timestamps against the media.
- [ ] Keep verbatim, clean transcript, and summary deliverables clearly distinct.

## Caption review (if requested)
- [ ] Cue numbers are sequential for SRT.
- [ ] Timestamps use the correct format and start/end order.
- [ ] Captions are synchronized to the source.
- [ ] Line breaks are readable and do not split phrases awkwardly.
- [ ] Punctuation and speaker identification are consistent.
- [ ] File opens in a plain-text editor and uses the requested format.

## Final package
- [ ] Deliver only agreed files.
- [ ] Use clear, consistent file names.
- [ ] Remove internal notes, placeholders, and unintended comments.
- [ ] Confirm requested language, spelling convention, and formatting.
- [ ] Include a concise delivery note and identify any unresolved uncertainties.
- [ ] Follow the agreed data-retention and deletion instructions.
