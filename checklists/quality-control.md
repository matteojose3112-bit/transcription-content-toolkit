# Transcription & Caption Quality Checklist

## Brief and source
- [ ] Correct source file and version used
- [ ] Language, deliverables, and verbatim level confirmed
- [ ] Client requirements and privacy instructions followed

## Transcript accuracy
- [ ] Replay checked for names, numbers, dates, and technical terms
- [ ] Speaker labels consistent and attribution reviewed
- [ ] Unclear audio marked rather than guessed
- [ ] Punctuation and paragraph breaks preserve meaning
- [ ] Any edits match the agreed transcript style

## Captions and subtitles
- [ ] Every cue has valid start and end times
- [ ] Cues appear in chronological order and do not overlap unintentionally
- [ ] Text is synchronized to speech
- [ ] Line breaks are readable and cues are not overloaded
- [ ] Punctuation, capitalization, and speaker identification are consistent
- [ ] File opens in the requested format/player

## Voiceover script
- [ ] Spoken narration is distinct from production notes
- [ ] Pronunciation guidance included where needed
- [ ] Numbers and abbreviations are written for natural speech
- [ ] Timing and target duration checked aloud

## Delivery
- [ ] Filenames are clear and match the agreed convention
- [ ] Requested formats and versions included
- [ ] Unresolved questions or limitations disclosed
- [ ] Final files reviewed after export
- [ ] No confidential source material included in public portfolio examples
