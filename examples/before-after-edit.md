# Sample: Verbatim vs. Clean Transcript

> **Fictional demonstration.** The lines below were written for this example and do not come from a real recording.

## Brief

Demonstrate the difference between a verbatim transcript and a lightly cleaned transcript while preserving the speaker's meaning.

## Verbatim version

**[00:00:02] Speaker 1:** So, um, what we usually do is, we call the customer back, usually the same day, if we can.

**[00:00:08] Speaker 2:** Right, and if they don't answer?

**[00:00:10] Speaker 1:** Then we, uh, leave a message and set a reminder to try again.

## Clean version

**[00:00:02] Speaker 1:** What we usually do is call the customer back the same day, if possible.

**[00:00:08] Speaker 2:** Right, and if they don't answer?

**[00:00:10] Speaker 1:** We leave a message and set a reminder to try again.

## Editing decisions

- Removed non-meaningful fillers in the clean version.
- Tightened phrasing without changing the stated process.
- Preserved the conditional phrase “if possible.”
- Kept timestamps and speaker labels aligned for easy comparison.

## Quality rule

Do not convert a transcript into a summary while labeling it “clean verbatim.” If a client requests a summary, create a separate deliverable and label it accordingly.
